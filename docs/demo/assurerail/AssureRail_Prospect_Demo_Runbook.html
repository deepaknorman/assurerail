Thirty-minute preflight

  1. Run the local integrity check.
    npm run demo:prospect:preflight
  2. Confirm public availability without exposing credentials.
    npm run demo:prospect:preflight -- --remote
  3. Run the authenticated browser gate. Use the adapted private fixture and require a completely green result before a live customer walkthrough.
    ARAIL_UX_AUTHORISED=yes \
ARAIL_UX_WEB_URL=https://assurerail.com \

ARAIL_UX_ACCOUNTS_FILE=/Users/DNorman/.assurerail-demo/prospect-demo-accounts.json \
npm run ux:e2e
  4. Open two separate browser profiles. Keep the Commercial Admin and Data Preparer sessions separate. Keep invoice operator identities private.
  5. Pre-stage the governed middle. Use a synthetic engagement whose quote and terms are accepted, whose invoice has been prepared and independently issued through the API control, and whose Razorpay test payment is reconciled.
  6. Confirm intake dependencies. Private object storage, ClamAV, the certified upload profile and the processing worker must all be healthy. Keep the AI provider in the approved shadow configuration.
  7. Open the fallback. Keep the mini-demo and https://assurerail.com/sandbox ready in separate tabs. The sandbox is a deterministic no-write product showcase.

Recovery cues

Observed issueImmediate response
Login or TOTP does not completeUse the already authenticated backup profile. Do not troubleshoot identity configuration in front of the prospect.
Checkout is unavailableUse the pre-staged paid engagement and show its issued statement and server-reconciled payment record.
Upload is rejectedConfirm category LOAN_TAPE and use the exact packaged file. Never bypass scanning or quarantine.
Processing remains queuedRefresh once after 45–60 seconds, then switch to the precomputed result.
AI provider is unavailableShow the explicit incomplete state and deterministic tape checks. Do not describe the assessment as complete.
Corrected result still says FIX_AND_REASSESSThis is expected. Show the resolved duplicate and the five missing EV evidence families separately.
Raw error or outageMove to the recorded mini-demo or /sandbox. Record the error for repair after the meeting.
